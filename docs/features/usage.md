# User Guide Overview

Welcome to the **Containery** user documentation. Select any of the feature guides below for detailed instructions on managing your Docker hosts, containers, images, storage, networks, users, and settings.

---

## Guide Directory

### [Dashboard & Host Overview](dashboard.md)
Monitor multi-host health, inspect system metrics (`docker info`), analyze disk space usage (`docker df`), and receive update notifications.

### [Container Management](containers.md)
Manage container lifecycles, filter by Docker Compose project, customize table columns, execute quick actions, stream real-time logs, view running processes (`top`), and open interactive web terminals (`exec`).

### [Image Management](images.md)
Browse cached Docker images, inspect image build metadata (architecture, OS, entrypoint, command, environment variables, labels), and remove unused images.

### [Volumes & Networks](volumes_networks.md)
Manage persistent storage volumes, inspect Docker network configurations, view assigned IPAM subnets and gateways, and list connected container endpoints.

### [User Management & RBAC](../administration/rbac.md)
Manage user accounts, assign roles, define custom roles, and configure granular permissions across 27 access controls.

### [Settings & Docker Hosts](../administration/settings.md)
Configure global application settings (dashboard refresh rate, session inactivity timeout, password length) and manage local or remote Docker host connections.

### [Personal Profile & Visual Themes](../administration/themes.md)
Customize display names, email addresses, passwords, light/dark mode themes, glassmorphism UI overlays, and background wallpapers.
