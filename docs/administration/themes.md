# Personal Profile & Visual Themes

Customize your individual user profile details, password, color theme, and glassmorphism interface effects.

---

## 1. Accessing User Profile Settings

* **Navigation**: Top-Right User Icon > **Profile**.

---

## 2. Personal Account Details

### Updating Name & Email

1. Navigate to **Profile** > **Personal Details**.
2. Update **Display Name** and **Email Address**.
3. Click **Save Profile**.

### Changing Account Password

1. Navigate to **Profile** > **Personal Details**.
2. Enter **Current Password**.
3. Enter **New Password** and confirm matching password.
4. Click **Update Password**.

---

## 3. Interface Themes & Glassmorphism UI

Customize your visual experience with live theme switching and glass backdrop effects.

* **Navigation**: **Profile** > **Personal Settings**.

### Theme Selection

Choose between four theme options:

* **Light**: Clean, high-contrast light mode interface.
* **Dark**: Modern dark theme optimized for low-light environments.
* **Dark Mixed**: Deep dark palette with accented container status hues.
* **System**: Automatically matches your system/OS preference (`prefers-color-scheme`).

### Glassmorphism UI Effect

* **Glassmorphism Toggle**: Enable or disable semi-transparent glass container panels with backdrop-filter blur effects.
* **Glass Background Preset**: Choose preset background artwork (e.g. `image:mountains`).
* **Custom Background URL**: Enter any custom image URL to serve as your desktop backdrop behind glass panels.
* Click **Save Personal Settings** to apply visual styles instantly across all pages.
